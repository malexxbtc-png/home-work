# Метеостанція: спільний протокол і піни (майстер ESP32 DevKit ↔ вузол ESP32-S3)

## Лінія UART (115200 8N1)

Рядок: `<JSON>*<CRC16>\n`. CRC16-CCITT (поліном 0x1021, початкове значення 0xFFFF), 4 hex-цифри, рахується
по байтах JSON до символу `*`. Розбір з кінця рядка (`strrchr('*')`). Максимум JSON 1023 байти
(на практиці: `wx` з 7 днями ≈ 490, `data` ≈ 170).

Wi-Fi, SNTP і запити до Open-Meteo виконує **майстер** (ESP32 DevKit). Вузол S3 радіо не використовує:
погоду і час він отримує по UART.

| З'єднання | Майстер | Вузол S3 |
|---|---|---|
| Передача майстра | GPIO17 (TX) | GPIO18 (RX) |
| Прийом майстра | GPIO16 (RX) | GPIO17 (TX) |
| Земля | GND | GND |

## Повідомлення

Майстер → вузол:
- `{"t":"data","T","RH","P","Td","alert":[..],"loc":[lat,lon],"sys":{"up","err","stm","pir"}}` кожні 5 с
  (T, RH, P, Td можуть бути null).
- `{"t":"wx","age":сек,"cur":{"T","w","g","dir","rain","snow","RH","cloud","code"},"fc":[{"cond","tmin","tmax","pop","wmax"}..]}`
  кожні 10 с. `age` = секунд від запиту до Open-Meteo (вузол за ним рахує застарілість), застарілі дані не шлеться.
- `{"t":"time","epoch":N}` кожні 10 с; N = Unix-час МІСЦЕВОГО годинника (UTC + Київ з літнім часом).
  Вузол ставить ним системний годинник (TZ = UTC), майстер за ним же коригує DS1307.
- `{"t":"snap","reason":"pir|wind|fog|ice|rain|snow|manual","seq":N}` запит фото.

Вузол → майстер:
- `{"t":"hb","cam":0|1,"sd":0|1,"tg":0}` кожні 5 с.
- `{"t":"snap_done","ok":true|false,"file":"YYYYMMDD/HHMMSS_<причина>.jpg","err":"...","seq":N}`.
  `err`: no_camera, no_sd, capture, encode, write, busy.

Будь-яке коректне повідомлення від вузла вважається ознакою «вузол на зв'язку» (таймаут 15 с).
Майстер дозволяє одне активне фото; відповідь чекає до 20 с, інакше подія позначається `timeout`.

## Піни майстра (ESP32 DevKit)

I2C 21/22 (OLED 0x3C, DS1307/DS3231 0x68, STM32 0x30), PIR 23, кнопки ADC 34, UART 17/16.

## Піни вузла (ESP32-S3 N16R8)

| Блок | GPIO |
|---|---|
| UART до майстра: TX / RX / IRQ | 17 / 18 / 16 |
| TFT на SPI2: SCK / MOSI / CS / DC / RST | 39 / 38 / 41 / 42 / 47 |
| SD на SPI3: SCK / MOSI / MISO / CS | 48 / 3 / 40 / 21 |
| OV7670: XCLK, SIOD, SIOC, VSYNC, HREF, PCLK | 15, 4, 5, 6, 7, 13 |
| OV7670: D0–D7 | 11, 9, 8, 10, 12, 14, 1, 2 |

Не використовувати 26–37 (flash, octal PSRAM). Схеми: `esp_devkit_master/docs`, `esp32s3_node/docs`.
