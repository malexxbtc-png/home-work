# Майстер: ESP32 DevKit (ESP-IDF)

Wi-Fi, SNTP і запити до Open-Meteo тепер на цій платі (`net_wx.c`); вузол S3 отримує погоду та час по UART.
Датчик MPU6050 видалено (разом із тривогами `tilt` / `shock`). Додано меню на OLED із резистивною клавіатурою
(ADKeyboard), журнал подій і запит фото в ESP32-S3.

Схема підключення: `docs/schema_master.svg` (PNG поруч).

## Збірка

    idf.py set-target esp32
    idf.py menuconfig        # Weather master network -> Wi-Fi SSID / password, координати (не комітьте sdkconfig)
    idf.py build flash monitor

ESP-IDF 5.3+ (перевірено на сумісність із заголовками 6.x лише читанням; новий драйвер I2C `i2c_master`, `adc_oneshot`). Залежність `espressif/cjson` підтягнеться сама.
Старі файли `mpu6050.c/h` з проєкту видаліть — у цьому архіві їх немає.

## Піни (`main/config.h`)

| Призначення | GPIO |
|---|---|
| I2C SDA / SCL (OLED 0x3C, DS1307/DS3231 0x68, STM32 0x30) | 21 / 22 |
| PIR (вихід) | 23 |
| Клавіатура ADKeyboard (ADC1_CH6, лише вхід) | 34 |
| UART2 TX → S3 GPIO18 | 17 |
| UART2 RX ← S3 GPIO17 | 16 |

У коді використовується UART1 з перепризначеними пінами 17/16. На платах із WROVER (PSRAM) GPIO16/17 зайняті: у `config.h` змініть `PIN_ESP_TX/RX`.

ADKeyboard живіть від **3,3 В**. Піну 34 внутрішніх підтяжок немає: без підключеної клавіатури ADC «плаває»,
і при старті може запуститися калібрування (воно завершиться таймаутом без збереження).

## Меню

Кнопки: **ВЛІВО/ВПРАВО** — екран, **ВГОРУ/ВНИЗ** — підсторінка або попередня/наступна подія,
**SELECT** — зробити фото (на екранах HOME і EVENT). Через 30 с без натискань — повернення на HOME.

| Екран | Що показує |
|---|---|
| HOME | час, дата, температура, рядок «остання подія» або поточна тривога |
| METEO | локальні датчики STM32: T, RH, P (гПа і мм рт. ст.), точка роси |
| WX | Open-Meteo (Wi-Fi на цій платі): вітер, пориви, опади, хмарність; ВГОРУ/ВНИЗ — прогноз на 3 дні |
| TIME | дата, час, день тижня, джерело часу (RTC / ESP32-S3 NTP) |
| EVENT | остання подія: тип, час, статус фото і файл; ВГОРУ — старіші (до 8) |
| STATUS | STM, Wi-Fi RSSI, вузол S3, SD, CAM, вік погоди |
| KEYS | напруга на ADC і розпізнана кнопка (перевірка клавіатури) |

## Калібрування кнопок

Номінали за замовчуванням: RIGHT 0, UP 430, DOWN 990, LEFT 1540, SELECT 2380 мВ, вільно ≈3,1 В.
Якщо у вашого модуля інакші: утримуйте будь-яку кнопку під час вмикання, на OLED з'являться підказки,
натискайте RIGHT, UP, DOWN, LEFT, SELECT по черзі. Значення зберігаються в NVS.
Екран KEYS показує поточні мВ, якщо треба підігнати вручну.

## Події і фото

Подія записується в журнал (останні 8; остання зберігається в NVS і переживає перезапуск) у випадках:
рух PIR (кулдаун 30 с), нова тривога `wind`/`fog`/`ice`/`rain`/`snow`, втрата/відновлення зв'язку з STM32 та ESP32-S3,
ручне фото, запуск. Для PIR і тривог майстер шле `{"t":"snap","reason":..,"seq":N}`; між автоматичними запитами —
не менше 60 с (`ALERT_SNAP_COOLDOWN_S`), одночасно виконується лише один знімок. ESP32-S3 відповідає
`snap_done` з іменем файлу (або помилкою); не відповів за 20 с — подія позначається `timeout`.
Вимкнути автоматичні фото: `SNAP_ON_PIR` / `SNAP_ON_ALERT` у `config.h`.

## Що не перевірено

Код не запускався на залізі. Логіку меню, клавіатури, подій, розбору погоди і тригерів перевірено
на ПК з заглушками ESP-IDF. Номінали кнопок і зсуви OLED можуть потребувати підгонки.

## Wi-Fi, час і погода

`net_wx.c`: Wi-Fi STA, SNTP (`pool.ntp.org`), запит до Open-Meteo кожні 15 хв. Параметри: menuconfig → Weather master network
(SSID, пароль, координати, часова зона). Порожній SSID вимикає мережу: тоді годинник іде за DS1307, а погоди немає.
Те саме повідомлення `wx` (див. `PROTOCOL.md`) розбирається на майстрі для екрана WX і тривог та щоразу надсилається вузлу.
Час SNTP, переведений у місцевий, коригує DS1307 (розбіжність більше 2 с).
Прошивка з Wi-Fi і TLS більша за стандартний розділ: у `sdkconfig.defaults` увімкнено `SINGLE_APP_LARGE` (1,5 МБ) і оптимізацію за розміром.
ADC1 (GPIO34, клавіатура) з Wi-Fi не конфліктує. Піки струму Wi-Fi: живіть плату від USB 5 В, ≥ 500 мА.
Після зміни `sdkconfig.defaults` видаліть `sdkconfig` або виконайте `idf.py fullclean`.
