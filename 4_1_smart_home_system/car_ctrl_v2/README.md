# Car control (ESP32-S3, ESP-IDF 5.x)

Плата: ESP32-S3. Команди `M:`/`S:` приходять з ESP32 DevKit (UART2), телеметрія з погодної станції (UART1).

- **Тяга:** колекторний мотор через L298N (ENA = PWM, IN1/IN2 = напрямок).
- **Кермо:** 28BYJ-48 через ULN2003 (4 входи), half-step, котушки вимикаються у спокої.
- **Дисплей:** MAX7219 8x8 — швидкість тяги цифрами у русі (без напрямку), бігучий рядок телеметрії, коли тяга 0.
- **Джойстик:** дві аналогові осі (ADC1) + кнопка. Вісь Y — тяга пропорційно відхиленню (центр = 0), кнопка — стоп. Кермо дивиться в напрямку вектора стіка.
- **UART1:** телеметрія `$SENS` від погодної станції.
- **UART2:** команди `M:`, `S:` від ESP32 DevKit.

## Підключення

| Пристрій | Сигнал | GPIO (за замовчуванням) |
|---|---|---|
| L298N | ENA (PWM) / IN1 / IN2 | 4 / 5 / 6 |
| ULN2003 | IN1 / IN2 / IN3 / IN4 | 7 / 8 / 9 / 10 |
| MAX7219 | DIN / CLK / CS | 13 / 14 / 15 |
| Погодна станція (UART2 TX, GPIO17) | → RX UART1 | 17 |
| ESP32 DevKit (TX команд) | → RX UART2 | 21 |
| Джойстик VRx (вісь X) | ADC1 | 1 |
| Джойстик VRy (вісь Y) | ADC1 | 2 |
| Джойстик SW (кнопка) | цифровий, pull-up | 38 |

Живлення: L298N і ULN2003 — від окремого джерела (5 В). GND усіх модулів і погодної станції з'єднати разом із GND ESP32-S3.

## Піни ESP32-S3

Поточні призначення перевірені за обмеженнями чіпа:

| GPIO | Використання | Перевірка |
|---|---|---|
| 1, 2 | джойстик X / Y (ADC1) | ADC1 = GPIO1..10 |
| 4, 5, 6 | L298N ENA / IN1 / IN2 | вільні |
| 7, 8, 9, 10 | ULN2003 IN1..IN4 | вільні |
| 13, 14, 15 | MAX7219 MOSI / CLK / CS | вільні |
| 16, 17 | UART1 TX / RX (телеметрія) | вільні |
| 21 | UART2 RX (команди DevKit) | вільний |
| 38 | кнопка джойстика | вільний, GPIO38 є на DevKitC-1 |

Заборонені для цього проєкту: 0, 3, 45, 46 (strapping), 19, 20 (USB), 26–37 (флеш і PSRAM), 39–42 (JTAG), 43, 44 (консоль і логи). При старті `pin_check()` звіряє піни з menuconfig. Якщо знайдено конфлікт, мотори не запускаються.

## Збірка

```bash
idf.py set-target esp32s3
idf.py menuconfig      # Car control — перевірити піни та параметри
idf.py build flash monitor
```

## Протокол UART (115200 8N1, рядки з `\r` або `\n`)

Телеметрія приходить на UART1, команди на UART2. Обидва порти розбираються однаково.

| Рядок | Дія |
|---|---|
| `$SENS,23.45,NA,1013.25*2C` | телеметрія, на матриці `T23.5 H-- P1013` |
| `M:50` / `M:-30` / `M:0` | тяга, −100..100 |
| `S:20` | кермо, градуси, обмежено ±`CONFIG_CAR_STEER_MAX_DEG` (за замовчуванням ±360) |

Контрольна сума — XOR усіх байтів між `$` і `*`.

## Примітки

- **Failsafe:** якщо немає `M:` довше `CONFIG_CAR_FAILSAFE_MS` (1 с), тяга зупиняється. Телеметрія на failsafe не впливає.
- **Кермо після старту** вважає поточну позицію центром. Калібрування немає.
- **Кермо ±360°** без кінцевих упорів: провідники не мають намотуватися. Якщо потрібен менший діапазон, змініть `CONFIG_CAR_STEER_MAX_DEG`.
- **Повний оберт 360°** на 2 мс між півкроками триває приблизно 8 с.
- **Команди від DevKit** приходять на окремий UART2, тож не конфліктують із телеметрією. GND DevKit, станції та S3 мають бути з'єднані.
- **Кут 28BYJ-48** рахується з `CONFIG_CAR_STEER_HALFSTEPS_PER_REV = 4096` (номінал редуктора 1:64). Реальний редуктор ~1:63.68, тож кут може відрізнятися на кілька відсотків. Для точного кута підберіть значення тестом (часто ~4076).

## Джойстик

- Живлення **3V3**, не 5V: ADC ESP32-S3 не розрахований на вищу напругу.
- Осі тільки на **ADC1** (GPIO1..10). ADC2 не використовуємо, бо він конфліктує з Wi‑Fi.
- Джойстик має стояти в центрі під час старту: центр міряється один раз.
- Коли джойстик працює, `M:` і `S:` з UART ігноруються. Якщо джойстика немає, керування з UART лишається.
- Вісь Y інвертується через `CONFIG_CAR_JOY_INVERT_Y`, якщо вгору тягне назад.
- Якщо кермо крутиться в протилежний бік, увімкніть `CONFIG_CAR_STEER_INVERT`. Якщо плутає право й ліво, увімкніть `CONFIG_CAR_JOY_INVERT_X`.
- Тяга пропорційна: центр = 0, перше відхилення за мертвою зоною дає `CONFIG_CAR_MOTOR_MIN_DUTY_PCT`, повне відхилення дає 100 %.
- Кнопка стіка зупиняє тягу. Тяга не повертається, доки стік не в центрі.
- Перевірте, що GPIO38 виведено на вашій платі. Якщо ні, змініть `CONFIG_CAR_JOY_SW_GPIO`.

## Поведінка

- **Тяга:** пропорційна стіку. Напруга на моторі обмежена `CONFIG_CAR_MOTOR_MAX_DUTY_PCT` (за замовчуванням 60 % для 12 В живлення і мотора 5 В). Мотор не стартує на малій шпаруватості, тому ненульова тяга мапиться на `CONFIG_CAR_MOTOR_MIN_DUTY_PCT` (35) … 100 %. Значення підбирають тестом.
- **Кермо:** кут = напрямок вектора стіка (0 = вперед, +90 = вправо). У центрі кут не змінюється. Довжина вектора має бути не менше `CONFIG_CAR_STEER_VECTOR_MIN_PCT` (40).
- **Матриця:** при тязі 0 показує телеметрію, при русі — швидкість цифрами (без напрямку). Якщо свіжих даних немає понад 3 с, показує `T-- H-- P--`.

## Схема з одним MOSFET (без реверсу)

Якщо мотор їздить тільки вперед, L298N не потрібен. Керування через N-канальний MOSFET IRL540N (або IRLZ44N).

```
ESP32 GPIO4 (ШІМ) ──[100 Ω]──┬── Gate   IRL540N
                             │
                          [10 kΩ]   (стягує gate до GND, мотор вимкнений при старті)
                             │
GND ─────────────────────────┴── Source

+V (батарея 2S, 8.4 В max) ──┬── мотор (+)
                             │
                 мотор (−) ──┴── Drain
          діод 1N5819: катод до +V, анод до Drain (паралельно мотору)
          конденсатор 100 нФ на клемах мотора (необов'язково)
```

- Пінування IRL540N (TO-220, фронтом до себе): G, D, S зліва направо.
- Джерело MOSFET і GND ESP32 і батареї з'єднати разом.
- Запобіжник 3–5 А на плюс батареї.
- BMS 2S обов'язковий для літій-іонних елементів.

У `menuconfig` вимкніть **Реверс мотора** (`CAR_MOTOR_REVERSE`). Тоді від'ємна тяга з джойстика дає 0.

Налаштування для батареї 2S (8.4 В повна, 6 В розряджена) і мотора 5 В:
- `CAR_MOTOR_MIN_DUTY_PCT = 25` (старт)
- `CAR_MOTOR_MAX_DUTY_PCT = 60` (при 8.4 В дає ~5 В, MOSFET не має падіння як L298N)

Якщо IRL540N гріється або мотор не тягне, замініть на IRLZ44N: він відкривається краще від логічних 3.3 В.

## Керування: Y — тяга, X — кермо

- **Вісь Y** — тяга: пропорційно відхиленню, центр = 0, від'ємні значення дають реверс (тільки з L298N, `CAR_MOTOR_REVERSE = y`).
- **Вісь X** — кермо: кут пропорційний відхиленню, центр = 0°, повний відхил = ±`CAR_STEER_MAX_DEG`. Вмикається `CAR_STEER_AXIS = y` (за замовчуванням).
- Режим `CAR_STEER_AXIS = n` лишає попереднє керування: кут за вектором стіка, кермо тримає кут у центрі.

Для L298N: `CAR_MOTOR_REVERSE = y`, `CAR_MOTOR_MIN_DUTY_PCT` і `CAR_MOTOR_MAX_DUTY_PCT` підберіть під напругу VS (падіння L298N ~2 В).
