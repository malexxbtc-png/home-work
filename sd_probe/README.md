# SD probe (ESP32-S3)

Окремий проєкт для діагностики SD по SPI. Піни в `main/main.c` (PIN_SCK/MOSI/MISO/CS).

    idf.py set-target esp32s3
    idf.py build flash monitor

Що друкується і як це читати:

1. `MISO GPIO.. підтяжка вгору=1, вниз=1` — MISO підтягнутий модулем/карткою (це норма).
   `вгору=1, вниз=0` — плаває (немає контакту з модулем). `0/0` — замкнений на GND.
   Те саме для CS.
2. Тест петлі: ВИТЯГНІТЬ картку і закоротіть дроти MOSI і MISO на модулі (або на платі між GPIO MOSI і GPIO MISO).
   Має з'явитись `<- петля працює`. Якщо ні, то проблема в піні/платі S3, а не в картці.
3. `CMD0 -> R1=0x01` — картка живa і чує. `0xFF` — тиша (живлення, MISO, CS). `0x00`/інше — шум.
4. `CMD8 -> 01 00 00 01 AA` — картка SD v2. Хибні байти — завади або немає 3,3 В на картці.
5. `ACMD41 готова` — ініціалізація пройшла; тоді проблема була лише в швидкості/проводах.
